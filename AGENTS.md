# AuroraLynx development and publication

- Preserve upstream licenses, copyright notices and provenance.
- Record changes and actual validation in CHANGELOG.md for every publication.
- AuroraLynx contributor credit belongs to ycrrongos only. Use ycrrongos as commit author and committer. Do not add assistant, AI or bot contributors or Co-authored-by trailers.
- Use AuroraLynx feature descriptions and its own preview images in the project introduction.
- Keep changes replayable through the AuroraAOSP patch stack and distinguish host checks from device verification.
- Never commit build outputs, credentials or temporary data.
